# 🔹 Project Plan for Khatabook App

# 1. Project Setup

-   Install Node.js & npm

-   Create project folder khatabook-backend

-   Initialize: npm init -y

-   Install Express: npm install express

# 2. Basic Server

-   Create server.js

-   Setup Express server with / route (Hello from Khatabook).

-   Run server with nodemon.
