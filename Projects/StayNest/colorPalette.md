# 🎨 StayNest — Complete Website Color Palette

## 1. Core Colors

| Category           | Tailwind Class | Hex       | Usage                           |
| ------------------ | -------------- | --------- | ------------------------------- |
| Primary Dark       | `slate-900`    | `#0F172A` | Navbar, Footer                  |
| Primary Dark Hover | `slate-800`    | `#1E293B` | Navbar hover, dropdown          |
| Primary            | `blue-600`     | `#2563EB` | Main buttons, important actions |
| Primary Hover      | `blue-700`     | `#1D4ED8` | Button hover                    |
| Primary Light      | `blue-50`      | `#EFF6FF` | Selected/active backgrounds     |
| Accent             | `orange-500`   | `#F97316` | CTA, highlights, special offers |
| Accent Hover       | `orange-600`   | `#EA580C` | Accent hover                    |
| Page Background    | `slate-50`     | `#F8FAFC` | Main website background         |
| Card Background    | `white`        | `#FFFFFF` | Cards, forms                    |
